# repo-tooling

Scripts and config applied to another repo. Run in place, only when invoked.

| Folder | What it does |
|---|---|
| `jookoi-graphify-setup/` | Applies the graphify config to a repo. See its README. |
| `webstorm-inspections/` | WebStorm inspection profile to import. See its README. |

No dependencies, so no `package.json`.
