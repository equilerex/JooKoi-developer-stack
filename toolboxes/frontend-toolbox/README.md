# frontend-toolbox

Framework-independent frontend skills. Start the agent here or copy single skills into a repo with `npm run copy:skill`.

| Skill | What it does |
|---|---|
| `animate` | Build an animation from scratch. |
| `animation-vocabulary` | Shared terms for describing motion. |
| `emil-design-eng` | Design-engineering guidance on motion and polish. |
| `find-animation-opportunities` | Find places in a codebase that need motion. |
| `improve-animations` | Audit and improve existing motion across a codebase. |
| `review-animations` | Critique one existing animation. |
| `visual-component-derivation` | Derive components from a visual design. |

Several animation skills look third-party. Check their licence before publishing. When a proper source exists, move them to a `package.json` dependency (see the manifest plan).
