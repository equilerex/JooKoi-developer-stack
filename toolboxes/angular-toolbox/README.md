# angular-toolbox

Skills for Angular work. Start the agent here (`cd toolboxes/angular-toolbox`, then `claude`) or copy single skills into a repo with `npm run copy:skill`.

| Skill | What it does |
|---|---|
| `jookoi-angular-performance` | Audit and fix bundles, lazy routes, SSR, hydration, change detection, assets. |
| `mobile-native` | Make a web app feel native on mobile. |

No dependencies, so no `package.json`. Skills live in `.agents/skills/`.
